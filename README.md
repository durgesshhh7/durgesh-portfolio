# Durgesh Rajpurohit — Portfolio

This is the existing React + Vite portfolio updated with the supplied images and content.

## Run locally
1. Open this folder in VS Code (the folder containing `package.json`).
2. Open **Terminal → New Terminal**.
3. Run `npm install` once.
4. Run `npm run dev`.
5. Open the local URL shown by Vite (usually `http://localhost:5173/`).

## Update content
Most text and image paths are in `src/data/content.js`.
Images are stored in `public/images/`. For example, `/images/durgesh.jpg` refers to `public/images/durgesh.jpg`.

## Before publishing
- Add real GitHub, LinkedIn, email, résumé and Fiverr URLs in `src/data/content.js`.
- Confirm project statuses, exact research titles, dates, client details and any public links before claiming them.
- No external project links or résumé file have been invented.
